# Dotidot 3.0

Klikací prototyp nové verze Dotidotu, ukázaný na datech Lidl Česká republika. Jeden HTML soubor bez backendu: všechna data jsou ilustrační a tlačítka, která by v reálu něco odeslala, jen ukážou zprávu.

## Jak to otevřít

- **Lokálně:** stáhni `index.html` a otevři ho v prohlížeči.
- **Online pro tým:** zapni GitHub Pages (Settings → Pages → Deploy from a branch → `main` / root). Prototyp pak poběží na `https://<owner>.github.io/<repo>/`.

## Co v prototypu je

| Sekce | Co ukazuje |
|---|---|
| Home | Výkon účtu, přínos Dotidotu, co Dottie změnila a co čeká na schválení |
| Products and feeds | Produkty, proměnné, produktové sety, feed exporty, zdroje |
| PPC | Google Ads, Microsoft Advertising, Sklik: cíl, výsledky, strategie, kampaně, PMax assety |
| Social | Meta a TikTok: cíl podle nových zákazníků, kampaně, kreativy, TikTok Shop, Creators |
| Creative | Knihovna, editor šablon s vrstvami, video šablony a video z promptu, konkurenční reklamy, brand kit |
| Product Analytics | Týdenní akční plán po produktech, Explore, přínos Dotidotu |
| Radar | Trh a konkurence |
| Dottie brain | Cíle, marže, sklad, kalendář, pravidla a kde se použily v rozhodnutích |
| Dottie | Pracovní panel s přílohami a příkazy, vysvětlivky u každé sekce |

**Pro mode** (přepínač vlevo dole) přidává detailní metriky a nastavení.

## Principy

- AI-first: Dottie navrhuje, generuje a hlídá. Nic se nezmění bez schválení, pokud to nedovolí pravidla.
- Každá změna od Dottie ukazuje, co mění, proč, z jakých dat a podle jakého pravidla.
- Základní režim je jednoduchý, Pro mode ukazuje vše.

## Stav

Prototyp pro interní diskusi, ne produkční kód. Čísla, tvůrci a konkurenti jsou smyšlení. Fakta o TikTok Shopu a Smart+ jsou z veřejných zdrojů k listopadu 2026 a je potřeba je ověřit v dokumentaci TikToku.
